# Drift — Intent-Driven Versioning

> **Git tracks what changed. Drift tracks *why* it changed — and who (or what) decided.**

Drift is a semantic version control layer that wraps Git. Every commit becomes an
**Intent**: the prompt that produced the change, the agent model behind it, the
AST-level mutations, an optional checkpoint of the agent's cognitive state, and a
cryptographic Ed25519 signature — all linked into an auditable, replayable graph.

Built for the AI era: when >80% of code is generated, text diffs are useless for
review. Drift rejects broken syntax before it ever enters history, lets you ask
*"why does this function exist?"* and get the originating prompt, and lets a
crashed agent resume from its last checkpoint.

## What you can do with it

| Capability | Command / Tool | Why it matters |
| :--- | :--- | :--- |
| Commit with intent | `drift realize -p "…"` | Rejects broken syntax (exit 2) — no history pollution |
| Semantic blame | `drift blame src/auth.ts --function verifyToken` | Get the originating prompt + model for any function |
| Reasoning hydration | `drift context src/auth.ts` | Last N intents for a file, to ground agents before editing |
| Crash recovery | `drift replay <intent-id> --checkout` | Restore an agent's checkpointed state |
| Verification gate | `drift verify <intent-id>` | Re-run the recorded verification command |
| Health | `drift doctor` | DAG integrity, signatures, orphan cleanup |

AI agents gain these as **MCP tools** (`drift_realize`, `drift_context`,
`drift_replay`, `drift_blame`, `drift_verify`, `drift_log`) via
[`@drift/mcp`](packages/drift-mcp).

## Quickstart (the 5-minute "aha")

```bash
npm install            # in this repo
npm run build

# seed the demo repository (real Drift history, generated by the CLI itself)
bash scripts/seed-demo.sh
cd examples/demo-repo

node ../../packages/drift-cli/dist/cli.js log
node ../../packages/drift-cli/dist/cli.js blame src/auth.ts --function refreshToken
```

`blame` prints the prompt, model and a **valid signature** for the function:

```
src/auth.ts:12 (refreshToken)
  AGENT @ Drift Demo
  model:   claude-3-5-sonnet
  prompt:  Fix race condition in token refresh by de-duplicating in-flight refreshes
  intent:  did_2941b4547b4ed505a7c37190247768a7
  commit:  087c492f…  signature: valid
```

### On your own repository

```bash
node packages/drift-cli/dist/cli.js init        # create .drift/ (SQLite DAG + key)
# … edit a file …
node packages/drift-cli/dist/cli.js realize -p "Fix race condition in token refresh" --agent --model claude-3-5-sonnet
node packages/drift-cli/dist/cli.js log
```

### As an MCP server for Claude Code / Codex / Cline

```json
{
  "mcpServers": {
    "drift": {
      "command": "node",
      "args": ["/abs/path/to/drift/packages/drift-mcp/dist/index.js"],
      "env": { "DRIFT_REPO": "/abs/path/to/your/repo" }
    }
  }
}
```

Agents then call `drift_realize` instead of `git commit`.

## Architecture (v0.1.0)

```
packages/drift-ast     Semantic parser + AST delta (ADDED/MODIFIED/DELETED/MOVED/RENAMED)
packages/drift-core    Intent store (SQLite, node:sqlite), git wrapper, Ed25519, redaction
packages/drift-cli     The drift CLI (bin: drift)
packages/drift-sdk     Typed SDK + Zod intent schemas
packages/drift-mcp     MCP server — delegates to the CLI (never touches git directly)
packages/drift-action  GitHub Action (composite, action.yml at repo root)
```

Storage is 100% dependency-free: **SQLite via Node's built-in `node:sqlite`**
(WAL, ACID), git via the git CLI, Ed25519 via `node:crypto`. Git compatibility is
strict (see `docs/git-compatibility.md`): `drift init` never rewrites history,
commits only carry a `Drift-Intent:` trailer, and deleting `.drift/` leaves a fully
functional git repo.

**Security defaults:** every intent is Ed25519-signed; prompts are regex-redacted
for secrets before any storage; telemetry is off; local operations make no network
calls. **Optional encryption at rest (v0.2.0):** set `[encryption] enabled = true`
in `.drift/config.toml` + `DRIFT_MASTER_KEY` to AES-256-GCM-encrypt the intent's
`prompt` and `agentState` (AAD-bound to the intent id). Note: the commit message
keeps the plaintext prompt by design (PRD §9.1), so git history remains readable
— see [SECURITY.md](SECURITY.md).

## Design decisions (ADR)

Rust was the PRD's original choice (ADR-003); this v0.1.0 ships **TypeScript-first**
because it delivers the full MVS (CLI + MCP + SDK) with zero native dependencies —
see [docs/adrs.md](docs/adrs.md#adr-006-v010-language-ts-first-not-rust) for the
trade-offs. The `drift-ast` parser interface is the drop-in point for a future
tree-sitter implementation.
